## Project Overview
The **Cultural Contextual Sentiment Analyzer** is a RESTful service that provides sentiment analysis tailored to cultural contexts. By leveraging transformer‑based language models and custom cultural embeddings, the system can distinguish sentiment nuances across different cultural backgrounds (e.g., American English vs. Indian English). This helps downstream applications—such as social media monitoring, customer feedback analysis, or market research—produce more accurate, culturally aware insights.

## Features
- **Multilingual & culturally aware** sentiment classification (supports English with regional variants out‑of‑the‑box; extensible to other languages).
- **FastAPI** powered HTTP API with automatic OpenAPI documentation.
- **Transformer** backbone (e.g., `distilbert-base-uncased`) fine‑tuned on culturally annotated sentiment data.
- **Scikit‑learn** post‑processing for calibration and threshold optimization.
- **Dockerizable** for production deployment.
- **Comprehensive test suite** using `pytest`.

## Architecture & Tech Stack
| Layer | Technology | Purpose |
|-------|------------|---------|
| API   | **FastAPI** | High‑performance asynchronous HTTP server, automatic docs |
| Model | **transformers** (Hugging Face) | Pre‑trained language model fine‑tuned for sentiment |
| Post‑processing | **scikit-learn** | Calibration, probability thresholds, optional feature engineering |
| Testing | **pytest** | Unit and integration tests |
| Containerization | **Docker** (optional) | Reproducible runtime environment |

## Installation

### Prerequisites
- Python **3.9** or newer
- `git` (to clone the repository)
- (Optional) Docker if you prefer containerized execution

### Steps
```bash
# 1. Clone the repository
git clone https://github.com/your-org/cultural-contextual-sentiment-analyzer.git
cd cultural-contextual-sentiment-analyzer

# 2. Create a virtual environment
python -m venv .venv
source .venv/bin/activate   # On Windows: .venv\Scripts\activate

# 3. Install dependencies
pip install --upgrade pip
pip install -r requirements.txt
```

**`requirements.txt` (excerpt)**
```
fastapi==0.110.0
uvicorn[standard]==0.27.0
transformers==4.40.0
torch==2.2.0
scikit-learn==1.4.2
pydantic==2.7.0
pytest==8.2.0
httpx==0.27.0
```

## Configuration
Configuration is managed via environment variables. Create a `.env` file in the project root (the file is ignored by Git) with the following keys:

```dotenv
# Model configuration
MODEL_NAME=distilbert-base-uncased
MAX_SEQ_LENGTH=128

# API configuration
HOST=0.0.0.0
PORT=8000
LOG_LEVEL=info
```

The service reads these variables using **pydantic**'s `BaseSettings`. Default values are provided if variables are omitted.

## Running the Service

### Development mode
```bash
uvicorn app.main:app --reload --host ${HOST:-127.0.0.1} --port ${PORT:-8000}
```

### Production mode (Gunicorn with Uvicorn workers)
```bash
gunicorn app.main:app \
    -k uvicorn.workers.UvicornWorker \
    -w 4 \
    --bind ${HOST:-0.0.0.0}:${PORT:-8000} \
    --log-level ${LOG_LEVEL:-info}
```

### Docker (optional)
```bash
docker build -t cultural-sentiment-analyzer .
docker run -d -p 8000:8000 --env-file .env cultural-sentiment-analyzer
```

## API Endpoints

| Method | Path | Description | Request Body | Response |
|--------|------|-------------|--------------|----------|
| `POST` | `/analyze` | Returns sentiment scores for a given text and cultural context. | `{"text": "...", "culture": "us_en"}` | `{"sentiment": "positive", "confidence": 0.92, "culture": "us_en"}` |
| `GET` | `/health` | Simple health check. | — | `{"status":"ok"}` |
| `GET` | `/docs` | Interactive Swagger UI (auto‑generated by FastAPI). | — | — |

### Request schema (`app/schemas.py`)
```json
{
  "type": "object",
  "properties": {
    "text": {"type": "string", "description": "Input text to analyze"},
    "culture": {
      "type": "string",
      "enum": ["us_en", "in_en", "uk_en"],
      "description": "Cultural variant of English"
    }
  },
  "required": ["text", "culture"]
}
```

## Example Usage

### Using `curl`
```bash
curl -X POST "http://localhost:8000/analyze" \
     -H "Content-Type: application/json" \
     -d '{"text":"I love the new features!", "culture":"us_en"}'
```

### Using Python (`httpx`)
```python
import httpx

payload = {"text": "The service was okay, not great.", "culture": "in_en"}
response = httpx.post("http://localhost:8000/analyze", json=payload)
print(response.json())
# Output: {'sentiment': 'neutral', 'confidence': 0.71, 'culture': 'in_en'}
```
